# **App Name**: Spinner Tasker.1

## Core Features:

- UI de la Ruleta Giratoria: Interfaz interactiva de ruleta giratoria con tareas definidas por el usuario que se muestran como opciones.
- Entrada de Tareas: Campo de entrada para que los usuarios agreguen tareas a la ruleta.
- Mostrar Tareas Aleatorias: Una sección de visualización donde la aplicación muestra los resultados de la ruleta después de que deja de girar.
- Visualización de la Lista de Tareas: Sección que enumera todas las tareas que introduce el usuario.
- Archivo de Tareas Completadas: Una lista separada para almacenar las tareas marcadas como completadas por el usuario.

## Style Guidelines:

- Azul celeste (#87CEEB) para tranquilidad y claridad.
- Amarillo dorado (#FFD700) para energía y optimismo.
- Blanco (#FFFFFF) para un diseño limpio y espacioso.
- 'PT Sans' (sans-serif) para una legibilidad moderna.
- Utilice iconos limpios y minimalistas para las categorías de tareas y la navegación, como una marca de verificación para las tareas completadas y un signo más para agregar nuevas tareas.
- La ruleta giratoria es el punto focal, centrada en la pantalla principal, con campos de entrada y listas de tareas de fácil acceso.
- Animación de giro suave y realista para la ruleta, con una pausa satisfactoria en la tarea seleccionada.
